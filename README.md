# 💸 Kharchapani

A full-stack expense tracker that helps you manage your daily spending and income with ease.  
Built using **React (Vite)** for the frontend and **Node.js + Express + MongoDB** for the backend.

---

## 🚀 Features
- Add, view, and delete transactions (income + expenses)
- Auto updates total balance
- JWT authentication with cookies
- Fully responsive frontend with charts
- Simple REST API backend
